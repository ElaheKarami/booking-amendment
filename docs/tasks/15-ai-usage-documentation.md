## Implementation Steps

1. Create `AI_USAGE.md` with AI tools, assisted areas, architecture/implementation/testing prompts, iterations, rejected or modified outputs, validation methods, limitations, and lessons learned.
2. Include two architecture prompts, two implementation prompts, one testing prompt, and one rejected or substantially changed output.
3. Explain ownership of architecture, correctness, security, testing, maintainability, documentation, and final quality.
4. Remove confidential account information, API keys, and irrelevant conversation content.

## Acceptance Criteria

- [ ] Prompts contain sufficient context, explicit constraints, assumptions, alternatives, and trade-offs.
- [ ] AI output is validated against requirements and framework behavior.
- [ ] The document explains rejected or modified suggestions and remaining risks.
