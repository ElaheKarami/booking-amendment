# Voyage Flow

## Load Options

Amendment form requires voyage options

↓

Request voyages using Port of Loading, Port of Discharge, cargo readiness date, and optional search

↓

Show loading, results, empty, or error state

## Select Voyage

User selects a voyage

↓

Update the amendment draft

↓

Validate selected-voyage cut-off compatibility and 40HC support

↓

Mark a valid assessment stale

## Search

User enters search criteria

↓

Use debounced search when selected as a performance measure

↓

Load matching voyage options
