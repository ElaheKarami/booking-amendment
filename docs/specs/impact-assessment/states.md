# States

## Not Calculated

No assessment exists for the current draft. Submission is disabled.

## Calculating

Recalculate is in flight.

## Valid

The assessment matches the current draft. Submission may proceed only when no blocking error exists.

## Stale

The form changed after assessment. Keep the previous result for review, disable submission, and require recalculation.

## Failed

Assessment failed. Show a meaningful error and allow recalculation.

## Validation and Impact

- Field validation error
- Informational message
- Business warning
- Blocking business error
- Charge change
- Approval requirement

An error-severity business validation blocks submission.
